How it works

1) Plan

Define a crisp task list and compute dependencies. Small blocks, sharp edges.

2) Fan‑out

Create parallel PRs with isolated scopes and shared conventions.

3) Gate & Merge

Run local gates, then merge top‑down through the pyramid. Boring merges, happy Fridays.
